        Privacy

        • Your original file is never stored. As a guest, its extracted text lives only in server memory and is deleted when you remove it, after 2 hours of inactivity, or when the server restarts.
        • If you sign in, the extracted text and search vectors of your documents are saved in a managed Redis database (Upstash) for up to 30 days so they survive restarts. Only you can open them, and you can delete them at any time.
        • To write each answer, your question and the most relevant passages are sent to one AI provider (Groq, OpenRouter, NVIDIA or Hugging Face — whichever is available; each answer shows which one). Nothing else about you is sent.
        • The page loads nothing from other websites — no analytics, no trackers, no third-party fonts.
